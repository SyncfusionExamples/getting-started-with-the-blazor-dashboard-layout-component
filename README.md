# Getting Started with the Blazor Dashboard Layout Component

**Repository Description**  
This repository contains a quick-start Blazor Server sample that demonstrates how to integrate and configure the Syncfusion Blazor Dashboard Layout component in a .NET 10 Blazor Web App.

A quick start Blazor project that shows how to add the Blazor Dashboard Layout component to a Blazor Server app. This project also includes example code to customize the Dashboard Layout using properties such as `Columns`, `SizeX`, and `SizeY`.

## Project Overview
The purpose of this project is to help developers understand how to build flexible and dynamic dashboards using the Syncfusion Blazor Dashboard Layout component. It demonstrates how dashboard panels can be arranged and resized to create responsive layouts in a Blazor Server application targeting .NET 10.

## Features
- Integration of the Syncfusion Blazor Dashboard Layout component
- Panel arrangement using configurable column layouts
- Custom panel sizing using `SizeX` and `SizeY` properties
- Responsive and interactive dashboard behavior
- .NET 10 Blazor Web App folder structure with Interactive Server render mode

## Prerequisites
Ensure that your development environment meets the following requirements:
- [Visual Studio 2022](https://visualstudio.microsoft.com/downloads/) or later, or Visual Studio Code
- [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later

## Installation and Running the Application
1. Clone the `getting-started-with-the-blazor-dashboard-layout-component` repository.
2. Open the project in Visual Studio 2022 or Visual Studio Code.
3. Restore NuGet packages by rebuilding the solution.
4. Build and run the application to view the Dashboard Layout output.

## Usage
Run the application and interact with the dashboard panels to observe layout behavior. Modify panel properties such as column count and panel size to experiment with different dashboard configurations.
